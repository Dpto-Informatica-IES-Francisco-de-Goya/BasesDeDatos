\subsection*{A. REDIS: Control de Sesiones y Contadores}
\begin{enumerate}[leftmargin=*, label=\textbf{P.R\arabic*:}]
    \item \textbf{(2,5 pts)} Implementa el siguiente flujo de inicio de sesión en Redis:
    \begin{itemize}
        \item Almacena el token de sesión con clave \texttt{sesion:token:XYZ}, valor \texttt{user\_id:101}, que expire automáticamente en \textbf{30 minutos}.
        \item Incrementa de forma atómica el contador global de sesiones iniciadas (clave: \texttt{stats:sesiones}).
        \item Indica qué comando usarías para consultar cuántos segundos le quedan al token antes de expirar.
    \end{itemize}
\end{enumerate}

\subsection*{B. MONGODB: Operaciones CRUD}
\begin{enumerate}[leftmargin=*, label=\textbf{P.M\arabic*:}, resume]
    \item \textbf{(3 pts)} Trabaja sobre la colección \texttt{experiencias} de la base de datos \texttt{globotour} (la misma usada en clase). Escribe los comandos necesarios para realizar las tres operaciones siguientes:
    \begin{enumerate}
        \item \textbf{(1 pt)} Inserta una nueva experiencia con los datos: nombre \lstinline{'Cata de vinos'}, tipo \lstinline{'Gastronomia'}, precio \texttt{45} y tags \lstinline{['romantico', 'adultos']}.
        \item \textbf{(1 pt)} Filtra todas las experiencias que tengan el campo \texttt{detalles} definido. Muestra únicamente el nombre y el precio de cada resultado, ocultando el \texttt{\_id}.
        \item \textbf{(1 pt)} Añade el tag \lstinline{'maridaje'} al array de tags de la experiencia \lstinline{'Cata de vinos'} sin sobreescribir los tags existentes.
    \end{enumerate}
\end{enumerate}

\subsection*{C. NEO4J: Consulta de Grafo}
