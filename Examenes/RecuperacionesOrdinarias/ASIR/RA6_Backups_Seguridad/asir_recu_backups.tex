\begin{tcolorbox}[title=Contexto del escenario]
Eres el administrador de base de datos de \textit{Logística Global S.L.}\ La empresa abre tres nuevas delegaciones durante tres días consecutivos. Tu tarea es gestionar el ciclo completo de copias de seguridad mientras se van registrando esas altas en la base de datos.
\end{tcolorbox}
