\section*{Instrucciones}
\begin{itemize}
    \input{../../instruccionesComunes.tex}
\end{itemize}
Crea un script SQL llamado \texttt{recu\_creacion\_asir.sql} que implemente el esquema descrito a continuación sobre una base de datos llamada \texttt{clinica\_vet}. El script debe ejecutarse de principio a fin sin errores, incluyendo el borrado previo de la base de datos si ya existe.

\begin{tcolorbox}[colback=red!5!white,colframe=red!75!black,title=\textbf{IMPORTANTE}]
Se evaluará la precisión en los tipos de datos, el uso de restricciones con nombre (\texttt{CONSTRAINT}) y el orden lógico de creación y borrado de tablas para respetar la integridad referencial.

\textbf{Optimización de tipos:} El alumno deberá elegir el tipo de dato entero más pequeño (\texttt{TINYINT}, \texttt{SMALLINT}, etc.) que permita almacenar el volumen de datos indicado en la sección \enquote{Estimación de Volumen}.
\end{tcolorbox}

\section{Esquema Relacional: Clínica Veterinaria}

\subsection*{Estimación de Volumen de Datos}
Para dimensionar correctamente los campos identificadores y numéricos, considera las siguientes previsiones de crecimiento de la base de datos:
\begin{itemize}
    \item \textbf{Propietarios:} 50.000 registros.
    \item \textbf{Mascotas:} 150.000 registros.
    \item \textbf{Veterinarios:} 100 registros.
    \item \textbf{Consultas:} 10.000.000 registros.
\end{itemize}

\subsection*{1. Tabla: \texttt{propietarios} }
\begin{itemize}
    \item \texttt{id\_propietario}: Numérico, clave primaria, autoincremental.
    \item \texttt{nombre}: Texto (100 caracteres), obligatorio.
    \item \texttt{telefono}: Texto (15 caracteres), obligatorio y único.
    \item \texttt{email}: Texto (100 caracteres), opcional.
\end{itemize}

\subsection*{2. Tabla: \texttt{mascotas}}
\begin{itemize}
    \item \texttt{id\_mascota}: Numérico, clave primaria, autoincremental.
    \item \texttt{nombre}: Texto (50 caracteres), obligatorio.
    \item \texttt{especie}: ENUM (\lstinline{'PERRO'}, \lstinline{'GATO'}, \lstinline{'CONEJO'}, \lstinline{'AVE'}). Obligatorio.
    \item \texttt{fecha\_nacimiento}: Fecha. Opcional.
    \item \texttt{id\_propietario}: Clave foránea a \texttt{propietarios}. Obligatorio. \textbf{[Relación 1:N]}
\end{itemize}

\subsection*{3. Tabla: \texttt{veterinarios}}
\begin{itemize}
    \item \texttt{id\_veterinario}: Numérico, clave primaria, autoincremental.
    \item \texttt{nombre}: Texto (100 caracteres), obligatorio.
    \item \texttt{num\_colegiado}: Texto (10 caracteres), obligatorio y único. Debe seguir el patrón de 2 letras seguidas de guión y 5 dígitos (ej: \lstinline{'CV-12345'}). [RA3-CE.e]
    \item \texttt{especialidad}: ENUM (\lstinline{'GENERAL'}, \lstinline{'CIRUGIA'}, \lstinline{'DERMATOLOGIA'}, \lstinline{'ODONTOLOGIA'}). Por defecto \lstinline{'GENERAL'}.
\end{itemize}

\subsection*{4. Tabla: \texttt{consultas}}
\textit{Registra cada consulta de una mascota con un veterinario. \textbf{Una mascota puede ser atendida por varios veterinarios y un veterinario atiende a varias mascotas} (relación N:M).}
\begin{itemize}
    \item \texttt{id\_mascota}: Clave primaria y clave foránea a \texttt{mascotas} (ON DELETE CASCADE).
    \item \texttt{id\_veterinario}: Clave primaria y clave foránea a \texttt{veterinarios} (ON DELETE CASCADE).
    \item \texttt{fecha\_consulta}: Clave primaria, tipo fecha.
    \item \texttt{motivo}: Texto (255 caracteres), obligatorio.
    \item \texttt{precio}: Decimal(6,2). Debe ser mayor o igual a 0.
\end{itemize}
\textit{Nota: La clave primaria es compuesta por los tres primeros campos.}
