\section{Ejercicios de Consultas}

\begin{enumerate}[leftmargin=*, label=\textbf{Consulta \arabic*:}]
    \item \textbf{(2,5 puntos)} % CE.c (Consultas resumen) - Peso 20% + redistribución -> 2.5 pts
    Muestra el ID del actor y el número de películas en las que ha participado, pero solo para aquellos actores que han rodado más de 35 películas. Ordena el resultado de mayor a menor número de películas.

    \item \textbf{(2,5 puntos)} % CE.d (Composiciones internas) - Peso 15% + redistribución -> 2.5 pts
    Listar el nombre y apellidos de los clientes (\texttt{customer}), junto con la dirección (\texttt{address}), la ciudad (\texttt{city}) y el país (\texttt{country}) donde residen. Ordena por país y luego por ciudad.

    \item \textbf{(2,5 puntos)} % CE.e (Composiciones externas) - Peso 15% + redistribución -> 2.5 pts
    Genera un listado de todas las categorías (\texttt{category}) de películas y el título de las películas que pertenecen a ellas. \textbf{IMPORTANTE:} Deben aparecer todas las categorías, incluso aquellas que no tengan ninguna película asignada (si las hubiera).

    \item \textbf{(2,5 puntos)} % CE.f (Subconsultas) - Peso 25% -> 2.5 pts
    Muestra el título de las películas cuya duración (\texttt{length}) sea superior a la media de duración de todas las películas de la base de datos. Utiliza una subconsulta.
\end{enumerate}
